# **Euphie — Assistente pessoal de inteligência artificial**

Projeto pessoal de desenvolvimento de uma assistente de IA utilizando Python, Ollama e o modelo de linguagem Qwen3, com foco na integração entre modelos locais, processamento de comandos e funcionalidades de assistência pessoal.

**Objetivos e atividades do projeto:**
- Desenvolver a estrutura de uma aplicação em Python para interação com modelos de linguagem.
- Explorar a execução local de LLMs e a integração com ferramentas externas.
- Implementar e aprimorar funcionalidades acionadas por comandos explícitos do usuário.
- Investigar e solucionar problemas de execução, configuração e integração entre componentes.
- Organizar o código para facilitar a manutenção e a expansão das funcionalidades.

**Próximas etapas:** aprimorar a arquitetura, ampliar a cobertura de testes e documentar o funcionamento da aplicação.

**Tecnologias:** Python, Ollama e Qwen3.

Projeto pessoal em desenvolvimento, utilizado para aprofundar conhecimentos em programação, integração de sistemas e aplicações com modelos de linguagem.
